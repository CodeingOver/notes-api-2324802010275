2. Ánh xạ 5 đặc tính điện toán đám mây theo NIST

  • On-demand self-service (Tự phục vụ theo yêu cầu): Tự khởi tạo và cấu hình Codespace chỉ bằng một cú click chuột trên giao diện GitHub mà không cần sự can thiệp thủ công từ quản trị viên.
  • Broad network access (Truy cập mạng rộng rãi): Truy cập và lập trình trực tiếp qua trình duyệt web trên mọi máy tính; mở Public port 3000 để truy cập API qua mạng Internet từ điện thoại.
  • Resource pooling (Gộp tài nguyên): Máy ảo Codespace và các container được cấp phát động từ cụm máy chủ dùng chung của GitHub/Azure Data Center, phục vụ nhiều người dùng đồng thời.
  • Rapid elasticity (Co giãn nhanh chóng): Có thể nâng hạ cấu hình phần cứng (chọn loại máy 2-core, 4-core,...) hoặc tăng dung lượng lưu trữ ngay lập tức khi khối lượng công việc thay đổi.
  • Measured service (Dịch vụ đo lường được): GitHub tự động đo lường thời gian hoạt động theo từng Core-giờ (Core-hours) và dung lượng đĩa sử dụng, hiển thị minh bạch tại trang Billing Usage.
